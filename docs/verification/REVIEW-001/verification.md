## 검증 항목

문서의 상대 경로·헤딩/HTML 앵커·정책 ID·현재/제안/이력을 검사했다. [문서 목록](documents.md)의 기존 52개가 이동 후에도 존재하며, 이동한 과거 본문 14개는 상태 표·링크 갱신·잘못 끊어진 인라인 개행 표기의 수정 외에 동일하다. 과거 실행 명령·결과는 보존했다.

README에서 삭제 요청한 과제명 문구가 없고 최소 설치·기동·빌드·API·AI 로깅 안내가 있는 것을 확인했다. 이번 검사는 Git 제외 로컬 검토 도구로 수행했으며 저장소용 문서 검사 도구 구현은 REVIEW-002로 인계한다.

| 확인 | 결과 |
| --- | --- |
| 문서 파일·로컬 링크/앵커 | 문서 67개, 깨진 파일·앵커 0건. 명시적 HTML id 포함 |
| 정책 정의 | 53개, 중복 정의·정의 없는 현행 참조 0건 |
| 과거 문서 | 14개 이동, 허용한 형식·링크 변경 외 전체 본문 보존 |
| 현재 API 예제 | 멤버 3개·그룹 2개 JSON 예제가 작업 전과 동일하며 파싱 성공 |
| 공유 OpenAPI | 두 파일 모두 HEAD와 바이트 동일 |

외부 웹 링크 전체의 가용성을 자동 검사하거나 과거 문서의 원래 명령을 재실행한 결과는 아니다. 링크 검사는 저장소 파일·앵커 범위다.

## 빌드

저장소 루트에서 `./gradlew.bat build --no-daemon --console=plain` 실행: **BUILD SUCCESSFUL, 30초, 실행 작업 4개·최신 상태 재사용 35개**. 포맷 자동 수정·공유 OpenAPI 갱신 명령은 실행하지 않았다.

| 서비스·검사 | 수 | 실패/오류/건너뜀 | 이번 실행 여부 |
| --- | --- | --- | --- |
| 멤버 일반 test | 128 | 0/0/0 | UP-TO-DATE, 이전 결과 재사용 |
| 그룹 일반 test | 28 | 0/0/0 | UP-TO-DATE, 이전 결과 재사용 |
| 멤버 OpenAPI 계약 생성 검사 | 8 | 0/0/0 | 새 실행, 2026-11-05T06:44:56.369Z 시작 |
| 그룹 OpenAPI 계약 생성 검사 | 1 | 0/0/0 | 새 실행, 2026-11-05T06:44:56.358Z 시작 |

일반 검사 156개는 이전 결과이며 새로 실행한 계약 검사 9개와 구분한다. 두 checkOpenApiSnapshot도 통과했다. 생성 파일은 build 아래에만 기록됐다. 이번 문서 작업 후 Compose 재배포·Swagger 브라우저·성능 측정·AI 수집기 회귀 테스트는 실행하지 않았다. 문서의 현재 JSON 예제를 읽는 기존 계약 검사는 새로 통과했다.

## 완료·대기 구분

응답 개정안은 사용자 확인 대기다. 문서 작성 완료를 계약 승인이나 코드 적용으로 표시하지 않는다. 커밋·develop 검토·master 병합은 아직 수행하지 않았다. REVIEW-002 생성은 REVIEW-001의 master 반영과 인계 확정 뒤다.

AI 수집 보류와 hook 실행 미확인은 [검토 결과](findings.md)를 따른다. 현재 턴이 끝나기 전에 최신 대화까지 스냅샷 제출 완료라고 판정하지 않는다.
