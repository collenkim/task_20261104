- JDK 21, Kotlin 2.3.21, Spring Boot 4.1.2, Gradle 9.3.0, MariaDB 11.8.9, JPA·Flyway 구성 유지.
- 멤버는 사용자 인증 없이 요청을 받으며 그룹은 공유 시크릿 헤더를 확인한다. 사용자 JWT·Swagger 자동 토큰 주입·그룹의 멤버 클라이언트를 제거했다.
