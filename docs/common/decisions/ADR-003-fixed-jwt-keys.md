# ADR-003 미리 생성한 고정 JWT 키·토큰 사용

| 항목 | 내용 |
| --- | --- |
| 분류 | 결정 기록 |
| 상태 | 대체됨, 2026-11-04. 현재 결정은 [ADR-005](ADR-005-member-edge-group-internal.md) |
| 당시 범위 | 사용자·Swagger·서비스 간 JWT 인증 |
| 현재 규칙 | 사용자 인증 제외, 내부 호출만 공유 시크릿 헤더 검증 |

초기에는 고정 RSA 키와 JWT를 생성하고 Swagger에 사용자 토큰을 자동 주입하기로 했다. 이후 사용자가 간단한 내부 키 방식으로 변경하도록 요청하여 해당 구현·설정·생성 작업을 제거했다.

현재 생성·교체 명령과 파일은 [보안 정책](../security.md)을 따른다. 이 문서는 과거 결정의 상태만 남기며 실행 안내로 사용하지 않는다.
